# Artify-social-networking-web-application
    A basic Full stack Social Networking Application built with of HTML, CSS, and Javascript, Node.js, Express.js, featuring user authentication and follow systems. The web application demonstrates a basic follow, login, and post functionalities. 

## Project Notes
    This project was developed during my second year as a learning-focused full-stack application.
The primary goal was to understand backend logic, database interaction, and authentication rather than UI design. Artify is a social networking website where the user creates an account, make text-based posts such as poems, stories or anecdotes,and follow or unfollow a user.

# Features

- Sign up and Login system
- input validation using Javascript and Regulay expressions
- Secure session-based authentication
- Create and publish posts
- Dynamic news feed
- Search for users
- Follow and unfollow users
- View posts from followed users
- Real-time updates using AJAX
- RESTful API (GET, POST, DELETE)


# How the website works

- User creates an account and logs in
- A session storage is created for the current user
- After login, the News Feed is dynamically loaded through Javascript
- User can: create a post, search for user, follow and unfollow any user
- Posts from followed users are retrieved from MongoDB and displayed
- When a user logs out, the session is destroyed on the serve
